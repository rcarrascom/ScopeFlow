# ScopeFlow

A pipeline dashboard for freelancers and consultants: track client projects
from lead to close, run a lightweight scope-call/technical-validation step
before you commit to the work, and get real analytics on what's actually
winning you business.

Built with FastAPI + vanilla JS - no build step, no external database, no
account required.

## Features

- **Pipeline table** with filters (status, timeline, stage, lead source) and
  a live search bar across client, project, and collaborator
- **Customizable columns**, saved locally per browser
- **Scope Call panel** per project - risk level, blockers, outcome, proposal
  status, notes
- **Qualification checklist** - budget confirmed, decision maker identified,
  timeline defined, success criteria, competing priorities
- **Look Up Collaborator** - view any collaborator's own pipeline
- **Bulk stage updates** - select multiple projects, move them all at once
- **Project Brief** - one-click copyable summary of a project
- **Closed Won Brief** - interactive, click-to-drill chart of won revenue by
  month
- **Stage Breakdown** - interactive chart of your pipeline by stage, any
  status slice
- **Pipeline Analytics** - win rate, weighted forecast, risk mix, win rate by
  lead source, and which qualification signals actually correlate with
  winning vs. losing deals
- **Mock CRM connect flow + "View in Salesforce" record view** - simulates
  what syncing this pipeline to a CRM like Salesforce would look like
- CSV / JSON / Markdown export

## Running it

```bash
./ScopeFlow.command
```

Creates a virtual environment on first run, installs dependencies (`fastapi`,
`uvicorn`, `jinja2`, `pydantic`), and opens the app at
`http://127.0.0.1:8004/ScopeFlow`.

To regenerate the sample dataset:

```bash
venv/bin/python generate_mock_data.py
```

## Data

Every client, collaborator, project, and note is synthetic, generated by
`generate_mock_data.py`. No real clients, no real credentials, no network
calls - the app is fully self-contained and safe to run offline.

## Structure

- `main.py` - FastAPI app and API routes
- `generate_mock_data.py` - dataset generator (run once, commit the output)
- `mock_data.py` - generated dataset (do not hand-edit)
- `templates/` - the dashboard UI and the mock CRM record page
